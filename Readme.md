HandNova – Gesture-Controlled Augmented Reality System

HandNova is an interactive, real-time hand-tracking application that transforms hand movements into dynamic neon visual effects. Using webcam-based hand detection, users can interact with a futuristic visual environment through simple hand gestures without touching a keyboard or mouse.

!!!!!Features:

Real-Time Hand Tracking: Detects and tracks up to two hands using MediaPipe.

Finger Landmark Detection: Tracks 21 hand landmarks for each detected hand.

Neon Hand Skeleton: Displays glowing connections between hand landmarks.

Gesture Recognition: Detects pinch gestures and estimates hand spread.

Interactive Particle Effects: Generates glowing particles around fingertips.

Shockwave Effects: Creates animated shockwaves when fingers perform a pinch gesture.

Two-Hand Interaction: Connects corresponding fingertips with dynamic neon lines.

Lightning Effects: Generates electric arcs between nearby fingers.

Mandala Visualization: Creates geometric patterns using both hands.

Dynamic Themes: Includes Rainbow, Cyberpunk, Lava, Ocean, and Galaxy themes.

Audio Effects: Generates interactive sound effects based on hand movements.

Matrix Background: Displays animated digital rain effects.

Performance Monitoring: Shows real-time FPS and detected hand count.

->How It Works

The webcam captures live video.

MediaPipe Hands detects hand landmarks.

JavaScript processes the detected hand coordinates.

Gesture recognition identifies hand movements and pinching.

The Canvas API renders neon effects, particles, lightning, and animations.

The Web Audio API generates interactive sound effects.

Getting Started::

Prerequisites

Visual Studio Code

Google Chrome or another compatible browser

Webcam

Internet connection

Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/HandNova.git

Navigate to the project folder:

cd HandNova

Open the folder in Visual Studio Code.

Open index.html using the Live Server extension.

Allow webcam access when prompted.

Click Enter Experience to start interacting.
